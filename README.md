# En Yavaş Hesap Makinesi Ever 🐢

## Bu Nedir?

Bu, **insanlık tarihinin en yavaş, en dramatik ve en anlamsız hesap makinesidir**. 

Normal hesap makineleri saniyeler içinde 1+1 yapar. Bu ise:

- Önce derin bir nefes alır
- Evrenin sırlarını düşünür
- Çay demler (hayali)
- Sonra belki, belki toplama yapar

Tamamen gereksiz. Tamamen mükemmel. Tamamen Türkçe.

## Nasıl Çalışır?

```bash
python yavas_hesap.py
```

Sana iki sayı sorar. Sonra **dram** başlar. Sabırlı ol. Ya da olma. Fark etmez, yine de yavaş.

## Özellikler

- Gerçekten çalışır (sonunda)
- Abartılı Türkçe mesajlar
- Rastgele beklemeler
- Hiçbir işe yaramaz ama eğlencelidir
- Copilot bile "bu ne ya" dedi (hayali konuşma)
